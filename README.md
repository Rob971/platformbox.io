# PlatformBox.io

Premium landing page for the 14-Day Enterprise Internal Developer Platform.

## Stack

- Next.js (App Router)
- React
- Tailwind CSS
- Framer Motion
- Lucide React

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```
